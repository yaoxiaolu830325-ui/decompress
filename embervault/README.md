# Embervault

A five-floor turn-based roguelite in a single HTML file. No install, no account, no ads, no tracking.

- Grid turns: you act, then every monster acts. Arrows / WASD / swipe, or the on-screen D-pad.
- Procedural dungeon each run: rooms, corridors, lava-lit fog of war, chests, stairs.
- Six monsters with different brains: rats wander, hounds chase, wisps shoot down open lanes,
  wardens move every other turn, brutes telegraph a charge, and the Emberheart volleys and splits.
- Four consumables (draught, fury tonic, smoke flask, rune bomb) and ten boons offered three at a time.
- Kill the Emberheart on floor 5 to clear the vault. Deepest floor, clears and best score persist.
- All art drawn procedurally on canvas; all sound synthesised with WebAudio (mute button, remembered).

Single file, zero dependencies, English UI. MIT for the code.
