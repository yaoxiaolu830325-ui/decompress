# Yao Arcade

Nine self-contained HTML5 games, playable at https://yaoxiaolu830325-ui.github.io/decompress/

| Game | Genre |
|---|---|
| `bubblewrap/` | Tactile bubble wrap |
| `silk/` | Light-ribbon drawing |
| `sand/` | Falling sand |
| `snake/` | Arcade snake |
| `breakout/` | Prism Break — brick-breaking arcade |
| `nightdrive/` | Nightdrive — arcade racing |
| `embervault/` | Embervault — turn-based roguelite |
| `foundry/` | Valve Foundry — fictional factory management |
| `prismshift/` | Prism Shift — optical puzzle |

No build step or external runtime dependencies. The original tactile toys (`bubblewrap/`, `silk/`, `sand/`) are MIT licensed.
