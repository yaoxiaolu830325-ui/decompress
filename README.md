# Decompress

Three tiny browser toys, each a single self-contained HTML file:

| Game | What it is |
|---|---|
| `bubblewrap/` | Infinite bubble wrap — drag to pop, bubbles stay dented |
| `silk/` | Draw glowing ribbons that flow and fall |
| `sand/` | Pour colored sand that piles and settles |

No build step, no dependencies, no tracking. MIT licensed.

Live: https://yaoxiaolu830325-ui.github.io/decompress/
