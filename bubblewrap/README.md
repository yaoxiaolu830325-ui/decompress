# 捏泡泡 · Bubble Wrap

Infinite bubble wrap in a single HTML file. No install, no account, no ads, no tracking.

- Drag across the sheet to pop; each bubble dents and stays dented
- Procedural pop sound (WebAudio, no asset files) and haptic tick on mobile
- "Pop the whole sheet" resets in one tap
